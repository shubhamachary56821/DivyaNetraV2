# DivyaNetra V2

Edge AI-based intelligent monitoring and decision support system.

## Hardware
- NVIDIA Jetson Orin Nano 8GB
- Two Logitech C170 USB cameras
- ESP32 (planned)

## Design Principles
- Reliability and safety first
- Manual activation
- Multi-purpose environment
- Modular architecture
- Edge-first processing
- Resource-aware AI scheduling
- Configurable event severity and response
- No gesture-based interface

## Operating Modes
- Standby
- Interactive
- Monitoring
- Custom

## Development
DivyaNetra V2 is developed independently of the legacy jarvisV2 project.
